# YouTube4KDownloader v1.3.4

[English](README.en.md) · [다운로드 / GitHub Releases](https://github.com/wjddn8480-spec/YouTube4KDownloader/releases)

Windows용 YouTube 영상·오디오 다운로드 프로그램입니다. 일반 MP4와 Premiere Pro 호환 MP4, 시간 입력으로 지정하는 여러 구간 다운로드, GPU 인코딩 선택을 지원합니다.

> 이 문서는 **미리보기 기능이 제거된 최신 1.3.4 수정본**을 기준으로 합니다. 정확한 자르기와 영상 미리보기는 제공하지 않습니다.

## 주요 기능

- 원본에서 제공하는 범위 내 최대 4K 다운로드
- 일반 MP4, Premiere Pro 호환 MP4, MP3, M4A 출력
- 여러 URL 대기열 및 전체 재생목록 다운로드
- 시작·종료 시간 직접 입력과 최대 100개 구간의 개별 저장
- CPU, AMD AMF, NVIDIA NVENC, Intel QSV 인코더 선택
- 대기열 진행률, 다운로드 속도, 예상 남은 시간 표시
- 병합·변환 시간을 포함하는 예상 시간과 이전 처리 기록을 이용한 보정
- 자막·자동 자막·썸네일 저장 및 메타데이터 삽입
- 클립보드 URL 자동 붙여넣기, 자동 대기열 추가, 추가 후 자동 시작
- 다운로드 기록, 기록에서 다시 다운로드, 완료 알림 및 폴더 열기
- 프로그램과 다운로드 도구 자동 업데이트
- Windows 언어 자동 감지 및 20개 언어 선택

## 실행 환경과 설치

- Windows 10/11 x64
- 인터넷 연결 및 다운로드·변환에 필요한 저장 공간
- GPU 인코딩 사용 시 해당 GPU와 호환 드라이버

배포 EXE는 .NET 런타임을 포함하므로 실행을 위한 별도 .NET 설치가 필요하지 않습니다.

1. [Releases](https://github.com/wjddn8480-spec/YouTube4KDownloader/releases)에서 `YouTube4KDownloader.exe`를 받습니다. 전체 소스 ZIP에서는 `release-assets/YouTube4KDownloader.exe`를 사용합니다.
2. 쓰기 권한이 있는 폴더에 저장하고 실행합니다.
3. 저장 폴더와 출력 형식을 선택합니다. 필요한 yt-dlp·FFmpeg·FFprobe는 도구 준비 과정에서 다운로드됩니다.

**같은 1.3.4 버전의 수정본으로 교체하는 경우:** 기존 앱을 완전히 종료한 뒤 EXE를 직접 교체하세요. 자동 업데이트는 더 높은 버전을 대상으로 하므로 같은 버전의 수정본은 자동 적용되지 않습니다.

## 기본 다운로드

1. URL 입력란에 영상 주소를 붙여넣습니다. 여러 주소는 줄바꿈이나 공백으로 구분합니다.
2. 저장 폴더, 최대 해상도, 출력 형식을 선택합니다.
3. 대기열에 추가하고 다운로드를 시작합니다.
4. 대기열에서 항목별 진행률·속도·남은 시간과 완료 여부를 확인합니다.

URL을 추가하자마자 다운로드하려면 자동 시작 옵션을 켜세요. 클립보드 관련 자동 기능은 화면에서 각각 켜거나 끌 수 있습니다.

## 출력 형식

| 형식 | 동작 | 용도 |
| --- | --- | --- |
| MP4 (일반) | MP4 영상과 M4A 오디오를 받아 MP4로 병합·리먹스합니다. 앱의 별도 영상 재인코딩을 거치지 않습니다. | 일반 재생·원본 코덱 유지 |
| MP4 (Premiere Pro 호환) | 다운로드한 소스를 H.264 영상 + AAC 오디오로 변환합니다. | Premiere Pro 편집 |
| MP3 | 오디오를 추출·변환합니다. | MP3 오디오 저장 |
| M4A | 오디오를 추출·필요 시 변환합니다. | M4A 오디오 저장 |

기본 출력은 **일반 MP4**이며 이후 선택한 형식을 기억합니다. 이전 기본값 전환이 아직 적용되지 않은 설정은 한 번 일반 MP4로 전환될 수 있습니다.

일반 MP4가 H.264를 보장하는 것은 아닙니다. 원본에 따라 AV1 등 다른 코덱이 포함될 수 있습니다. 편집 호환성이 필요하면 Premiere Pro 호환 모드를 선택하세요. 해당 해상도의 MP4 스트림이 없으면 일반 MP4는 낮은 해상도를 선택하거나 실패할 수 있습니다. 선택한 해상도는 상한이며 원본보다 높은 해상도로 업스케일하지 않습니다.

## 구간 다운로드

### 한 구간 저장

1. 개별 영상 URL을 입력하고 **구간 다운로드**를 체크합니다.
2. 시작과 종료 시간을 입력합니다.
3. 목록에 구간을 추가하지 않은 상태에서 다운로드를 시작하면 입력한 한 구간을 저장합니다.

| 입력 예 | 의미 |
| --- | --- |
| `90` | 90초 |
| `01:30` | 1분 30초 |
| `00:01:30` | 1분 30초 |
| `00:01:30.500` | 1분 30.5초 |

종료 시간은 시작 시간보다 커야 합니다. 영상 길이를 확인할 수 있으면 범위 초과도 검사합니다.

### 여러 구간 저장

1. 시작·종료 시간을 입력하고 **+ 구간 다운로드**를 누릅니다.
2. 시간을 변경해 필요한 구간을 계속 추가합니다.
3. 목록에서 항목을 선택해 제거하거나 전체 지우기로 비울 수 있습니다.
4. 다운로드를 시작하면 각 구간을 별도 대기열 항목과 파일로 저장합니다.

**구간 목록이 있으면 현재 입력 칸보다 목록이 우선합니다.** 최대 100개를 추가할 수 있고 완전히 같은 구간은 중복 추가하지 않습니다. 여러 URL에는 같은 구간 목록을 각각 적용합니다. 각 구간의 성공·실패와 진행률을 별도로 표시합니다.

### 구간 기능의 범위

- 빠른 자르기만 사용하며, 키프레임에 따라 시작·끝이 약간 달라질 수 있습니다.
- 일반 MP4, Premiere 호환 MP4, MP3, M4A에 적용됩니다. Premiere 호환 모드는 자른 결과도 H.264/AAC로 변환합니다.
- 구간 모드에서는 전체 재생목록, 진행 중인 라이브, 자막 저장을 지원하지 않으며 챕터를 삽입하지 않습니다.
- 파일명에 구간·처리 방식·형식 정보를 붙여 전체 영상과 구분합니다.
- 구간 설정과 목록은 앱을 다시 실행하면 초기화됩니다.
- FFmpeg가 필요하며 서버·스트림 방식에 따라 지정한 구간보다 많은 데이터를 받을 수 있습니다.

## GPU 인코딩

출력 형식을 **MP4 (Premiere Pro 호환)**으로 선택한 뒤 인코더를 고릅니다.

| 선택 | 인코더 |
| --- | --- |
| CPU — 기본값 | `libx264` |
| AMD AMF | `h264_amf` |
| NVIDIA NVENC | `h264_nvenc` |
| Intel QSV | `h264_qsv` |

선택값은 저장됩니다. 일반 MP4·MP3·M4A에는 이 선택이 적용되지 않습니다. GPU 인코딩이 다운로드 자체의 네트워크 속도를 높이는 것은 아닙니다.

앱은 GPU 사용 전 짧은 테스트 인코딩으로 기본 사용 가능 여부를 확인합니다. 사용할 수 없으면 오류를 표시하며 CPU를 직접 선택해 다시 시도할 수 있습니다. 테스트를 통과해도 실제 영상의 해상도·형식에 따라 변환이 실패할 수 있습니다. 인코더마다 화질과 용량이 달라질 수 있습니다.

## 진행률과 예상 시간

- 대기열과 상태 영역에 진행률, 속도, 예상 남은 시간을 표시합니다.
- 다운로드 중에는 전송 속도를, 후처리 중에는 측정 가능한 경우 `2.00x` 같은 처리 배속을 표시합니다.
- `≈`는 추정값입니다. 현재 전송과 예정된 병합·변환 시간을 반영하며 **대기열 전체 완료 시간은 아닙니다**.
- 전송 단계가 바뀌면 진행률과 시간이 조정될 수 있습니다. 모든 처리가 성공해야 항목이 100% 완료됩니다.
- 이전에 성공한 처리 시간을 형식·선택 해상도·처리 종류별로 기록하며 GPU 인코더도 구분합니다.
- 초기에는 기본 가정을 사용하고, 기록이 쌓이면 다음 작업의 예상 시간에 반영합니다. 취소·실패한 작업과 측정값이 없는 작업은 학습하지 않습니다.
- 속도 변동은 완화해 표시합니다. 처리 정체나 예상 초과 등으로 시간을 판단하기 어려우면 ‘계산 중’을 표시할 수 있습니다.

영상 복잡도, 실제 코덱·FPS, PC 부하, 저장장치에 따라 오차가 발생합니다. 예상 시간의 정확도나 완료 시각을 보장하지 않습니다.

## 자막·썸네일·브라우저 로그인

전체 영상 다운로드에서는 자막, 자동 자막, 썸네일 및 메타데이터 옵션을 사용할 수 있습니다. 자막은 원본 제공 여부에 따라 달라지며 한국어·영어 계열을 대상으로 합니다.

로그인이 필요한 콘텐츠는 본인 계정으로 접근 가능한 범위에서 브라우저 로그인 또는 `cookies.txt`를 사용할 수 있습니다. 현재 UI의 브라우저 선택은 Firefox·Brave입니다. 접근 제한을 우회하거나 다운로드 가능성을 보장하는 기능은 아닙니다. 쿠키 파일에는 로그인 정보가 포함될 수 있으므로 공유하거나 저장소에 올리지 마세요.

## 프로그램·도구 업데이트

### 프로그램

자동 업데이트 옵션을 켜면 실행 시 및 실행 중 약 6시간마다 GitHub Releases를 확인합니다. 앱 업데이트 버튼으로 수동 확인할 수도 있습니다. 업데이트 적용은 진행 중인 작업과 대기열을 마친 뒤 수행합니다.

### 도구

| 도구 | 역할 |
| --- | --- |
| yt-dlp | 영상 정보 추출과 다운로드 |
| FFmpeg | 영상·오디오 병합, 구간 처리, 변환 |
| FFprobe | 미디어 정보와 재생 길이 확인 |

도구 자동 업데이트는 마지막 성공 확인 후 24시간이 지나면 유휴 상태에서 확인합니다. 실패하면 약 1시간 후 다시 시도합니다. 도구 업데이트 버튼으로 수동 실행할 수도 있습니다.

## 설정과 기록

기본 저장 위치: `%LOCALAPPDATA%\YouTube4KDownloader`

| 파일 | 내용 |
| --- | --- |
| `settings.json` | 출력 형식, 인코더, 저장 폴더, 언어, 자동 기능 설정 등 |
| `history.json` | 다운로드 기록 |
| `timing-history.json` | 예상 시간 보정용 처리 기록 |

예상 시간 학습값을 초기화하려면 앱 종료 후 `timing-history.json`을 삭제하세요. 대기열과 구간 목록은 재실행 시 복원되지 않습니다.

## 소스 빌드

Windows에 .NET 8 SDK를 설치하고 소스 루트의 `build_release.bat`를 실행합니다.

```bat
build_release.bat
```

결과: `release-assets/YouTube4KDownloader.exe`

직접 게시하려면 소스 루트에서 다음 명령을 사용할 수 있습니다.

```powershell
dotnet publish .\YouTube4KDownloader\YouTube4KDownloader.csproj -c Release -r win-x64 --self-contained true -o .\release-assets
```

태그와 EXE 내장 버전이 일치해야 합니다. 태그만 변경해도 EXE 버전이 바뀌지는 않습니다. 동일한 1.3.4 수정본을 다시 올려도 이미 1.3.4를 실행하는 사용자는 직접 교체해야 합니다.

| 증상 | 확인할 내용 |

| 다운로드 실패 | 도구 업데이트, URL 접근 가능 여부, 로그, 로그인 설정 확인 |

## 검증 범위
